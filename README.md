# Simon Says Game 🎮 (<a href="syed-shayzan.github.io/Simon-Says-Game">Live preview</a>)

An interactive, browser-based memory game inspired by the classic **Simon Says** toy. Built using HTML, CSS, and JavaScript, this project tests and trains visual memory by generating increasingly complex sequences of colors that players must repeat correctly.

---

## 🌟 Key Features

- **Progressive Difficulty:** Each successful round adds a new step to the color sequence.
- **Visual Feedback:** Smooth CSS flash animations highlight buttons when activated by the game or clicked by the player.
- **Score Tracking:** Tracks the user's current level and displays high scores on gameover.
- **Game Over Detection:** Detects incorrect button presses, flashes a red screen effect, displays the final score, and allows instant restarts.
- **Responsive Layout:** Works smoothly on desktop and mobile browsers.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for game board and control panels.
- **CSS3:** Custom styling, flexbox layout, color palette, and animations for button flashes.
- **JavaScript (ES6):** Core game logic, DOM manipulation, state management, and event listeners.

---

## 🚀 How to Play

1. Open the game in any modern web browser.
2. Tap the start button to launch the game.
3. Watch carefully as one of the four colored buttons flashes.
4. Click the exact same button sequence shown.
5. If you match the sequence correctly, the game advances to the next level and adds one more step to the pattern.
6. If you press the wrong button, the game ends!Tap start button to reset and try to beat your high score.
